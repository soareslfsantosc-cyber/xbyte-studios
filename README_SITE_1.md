# Primeiro site — versão original

**Branch:** [`main`](https://github.com/soareslfsantosc-cyber/xbyte-studios/tree/main)

**Página inicial:** `index.html`

Esta é a versão original do site da Xbyte Studios, com páginas institucionais e uma vitrine de produtos de hardware.

## Páginas e arquivos

- `index.html` — página inicial, catálogo de produtos, filtros e comparação.
- `about.html` — apresentação institucional, missão, história, equipe e formas de contato.
- `quantom ai.html` — página de conteúdo sobre computação quântica e inteligência artificial. O nome do arquivo é mantido como está nesta branch.
- `style.css` — estilos do site.
- `script.js` — interações e funcionalidades front-end.

## Recursos

- Catálogo dinâmico de produtos.
- Busca e filtros por socket e faixa de preço.
- Seleção e comparação de produtos.
- Seções informativas sobre formas de pagamento e suporte técnico.
- Navegação entre as páginas institucionais.
- Layout responsivo e recursos de acessibilidade presentes na interface.

## Executar localmente

Não é necessário instalar dependências ou compilar o projeto. Na raiz do repositório, com a branch `main` selecionada, execute:

```bash
python3 -m http.server 8000
```

Depois abra <http://localhost:8000> no navegador. Para encerrar o servidor, use `Ctrl+C` no terminal.
